================================================================================
GODOT 4 USAGE INSTRUCTIONS
================================================================================

1. OPTION A: AnimatedSprite2D Setup (Recommended)
-------------------------------------------------
1. In your Boss scene, select or add an AnimatedSprite2D node.
2. In the Inspector, under 'Animation', click 'SpriteFrames' -> 'New SpriteFrames'.
3. Click the SpriteFrames panel at the bottom of the Godot editor.
4. Click the 'Add frames from a sprite sheet' button (small grid icon).
5. Select the corresponding sheet (e.g., idle.png).
6. Set:
   - Horizontal: 4 (or according to Hframes column above)
   - Vertical  : 1
7. Select all frames and click 'Add 4 Frame(s)'.
8. Repeat for walk, attack, hurt, and death animations with their respective Hframes.
9. Ensure 'Texture Filter' in CanvasItem -> Texture -> Filter is set to 'Nearest'.

2. OPTION B: Sprite2D + AnimationPlayer Setup
--------------------------------------------
1. Add a Sprite2D node and assign the texture (e.g. res://output/ogre_boss/idle.png).
2. In Inspector -> Animation:
   - Hframes: 4
   - Vframes: 1
   - Frame  : 0
3. In AnimationPlayer, create an 'idle' track keyframing the 'frame' property:
   - Values: 0, 1, 2, 3
4. Set Track length to 0.8s (0.2s per frame = 5 FPS) and enable Looping.
